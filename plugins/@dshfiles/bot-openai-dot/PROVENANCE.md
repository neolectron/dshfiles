This package is a separately licensed **AGPL-3.0-only** TypeScript port of the native messaging behavior in [Beeper chatgpt-dots](https://github.com/beeper/chatgpt-dots/tree/ee43cb5c2b8a27e0759d74fb14b24d749ce01fdb), pinned to `ee43cb5c2b8a27e0759d74fb14b24d749ce01fdb`. The TypeScript translation and DSH glue are distributed under that same license, not the surrounding repository's MIT license. The package ships its source, fixtures and build configuration alongside the bundle for corresponding-source access.

## Source mapping

- [`pkg/chatgpt/client.go`](https://github.com/beeper/chatgpt-dots/blob/ee43cb5c2b8a27e0759d74fb14b24d749ce01fdb/pkg/chatgpt/client.go): JWT account-binding hints, identity-preserving renewal, primary/by-thread discovery, verified rooms, stable send IDs, bounded message pages. Ported into `src/protocol.ts`, `src/http.ts`, `src/adapter.ts`.
- [`pkg/connector/login.go`](https://github.com/beeper/chatgpt-dots/blob/ee43cb5c2b8a27e0759d74fb14b24d749ce01fdb/pkg/connector/login.go): explicit broad-account warning, exactly two room members, token-user mapping and latest-message since-link baseline. Browser credential extraction is **not** ported.
- [`pkg/connector/client.go`](https://github.com/beeper/chatgpt-dots/blob/ee43cb5c2b8a27e0759d74fb14b24d749ce01fdb/pkg/connector/client.go): three-second REST polling, chronology, sender mapping and request reconciliation. DSH's neutral Host owns persistence/outbox/scheduling rather than porting the Matrix bridge.
- [`pkg/chatgpt/signals.go`](https://github.com/beeper/chatgpt-dots/blob/ee43cb5c2b8a27e0759d74fb14b24d749ce01fdb/pkg/chatgpt/signals.go): inspected for room verification and real-time signals. WebSocket/presence/typing/read receipts are deliberately **not** implemented or advertised.

No Go, Matrix bridge, daemon, dependency tree, proxy rotation, browser/cookie extraction, impersonation or challenge bypass is included. This is a protocol port, not an official OpenAI SDK. Source URLs and commit are public; no private credentials or history were accessed to implement or test it.

## Deliberate differences

- Secrets are canonical credential-port references and resolve only on the Host. Renewal defaults to memory-only. DSH-specific `src/credentials.ts` adds an optional explicitly granted, post-verified-identity lifecycle: one fresh global managed JSON session bundle, one atomic Core reference-map publication, then whole-scalar updates to that same item. Existing user scalar aliases are never overwritten or deleted. Public Catalog create/update is Host-only; reads use credential-port, never reveal RPC. Bundles bind their own canonical reference (selected before creation), connection, generation and verified account; managed writes also require the generated alias pattern, rejecting bundles copied to another user alias. This is accidental-provenance protection, not cryptographic ownership proof. Unresolved persistence failure stops messaging. This is not backend CAS, a transaction or cross-host coordination. Provider-refresh/local-commit crash windows and already accepted writes can require reauthorization; cancellation does not undo accepted backend work. See README for recovery and consent semantics.
- All HTTP requests are fixed HTTPS `chatgpt.com` allowlisted paths. Redirects are rejected, bodies capped, cancellation/timeouts applied and errors replaced with a fixed redacted vocabulary. An exact403 `cf-mitigated: challenge` is identified as a browser security check, not a proven OAuth rejection; no challenge body or private header is echoed.
- Valid nullable response fields preserve upstream zero-value behavior: `latest_messages: null` becomes no embedded baseline and uses the existing single-message fallback; `content.text: null` becomes empty text. Attachments/elicitation/deletions retain existing safe notices. Malformed non-null types, bounds and room/author guards remain enforced.
- Room membership is reverified before each poll/send/reconciliation, not only once at link time. Unknown authors and identity changes are rejected.
- Poll pages and reconciliation are bounded. Each poll checks at most one additional recent 32-message page for edits/deletions and deduplicates stable IDs; the versioned opaque polling cursor carries the recent anchor. Older edits beyond that horizon may remain stale. Reconciliation starts at the original persisted since-link checkpoint passed by the neutral Host; incomplete scans return `unknown` and must not justify a duplicate send.
- Unsupported attachments/elicitation become a safe notice and fixed native ChatGPT handoff. Inline approvals and media are not capabilities.

## Important transport exclusion

The pinned upstream connector also contains `pkg/connector/proxy.go` (unchanged in current `05bfac9f682bf27e73d5c87755245031f556a066`). Its [`newEgress`](https://github.com/beeper/chatgpt-dots/blob/05bfac9f682bf27e73d5c87755245031f556a066/pkg/connector/proxy.go) uses Chrome impersonation, browser-style headers and selected Cloudflare cookies; the [runtime connection](https://github.com/beeper/chatgpt-dots/blob/05bfac9f682bf27e73d5c87755245031f556a066/pkg/connector/client.go) selects that transport even without a configured proxy. **None of this layer is ported.** Request-builder/header parity does not prove equivalent transport or ordinary Node HTTP acceptance. Do not add impersonation, cookie transfer, proxy rotation or challenge-solving to reproduce upstream behavior.

The renewed authorized Node read received the explicit challenge marker. Normal first-party browser reads for the same account succeeded and exposed the nullable decoding fixes above; their success is browser-side protocol evidence, not deployed Node authorization or proof that the Codex OAuth grant is accepted by Dot.

## Fixture-only human viewer port

The new authentication attempt/transport/viewer/worker sources are **unwired, source/fixture-only**. They do not implement or prove production sign-in or credential capture. Reviewed pixel-coordinate, keyboard/IME and fixed page-owned mouse-event dispatch mechanics are narrowly ported from MIT `drscrewdriver/dsh-browser-cdp` at `da9891b9c8ee64b6c4da16d3ae654d0f1166cccd`; the complete original notice, exact hashes, excluded unsafe subsystems and update policy are in [NOTICE.md](NOTICE.md). Never install its general browser bundle or reuse its cookie-presence authentication, profile import/discovery, control listener, tools or teardown.

The managed worker currently accepts only an explicit synthetic local fixture policy, disables JavaScript and requires positive execution-world evidence. That is deliberately not a usable ChatGPT authentication policy. Real native admission, browser rendering, privacy/egress, diagnostics and full-range cleanup remain separate proof gates.

## Updates

No runtime upstream fetches or automatic protocol updates. A maintainer must review changes against this exact pin, deliberately change the pin/source mapping, preserve the full license and attribution, update local fixtures for request/identity/auth/cursor behavior, run package test/typecheck/build/import checks, and obtain separate explicit authorization before any real-account validation. Upstream features never silently expand this adapter's advertised capabilities. Challenge or schema changes fail closed rather than starting circumvention. Distributing modified source/bundles requires following the AGPL, including applicable corresponding-source/network-use obligations; keep this package's source available with deployments.
