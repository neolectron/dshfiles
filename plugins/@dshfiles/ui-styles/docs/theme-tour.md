# Theme tour

A 20-second tour of the gallery themes. In a DSH thread, mention this file and ask the agent to run it.

---

Quick theme tour (~20 s): call `theme_get` and remember my settings. If I'm in dark mode, show Snow Pines, Aurora,
Night Reef, Paper Garden; in light mode, Halftone, Honu Lagoon, Plotter Tide, Paper Garden. For each: `theme_set` it,
write its name in one short line, `sleep 5`. On the last one only, use `readingBlur` 8 to show the blur. Then put my
settings back.
